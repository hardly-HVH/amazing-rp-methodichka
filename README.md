# Amazing RP — Государственная методичка

Государственная методичка для Amazing RP: полный свод законов и регламентов (Конституция, УК, КоАП, ФЗ, УИК, ПДД, Устав ОВД, ОУР, ОСН «Гром», административные регламенты и кейсы).

## Возможности
- 📚 200+ документов
- 🔍 Живой поиск по названию, тексту и тегам
- 🗂 Фильтры: Все / Статьи / НПА / Кейсы
- 🌙 Переключатель тёмной/светлой темы
- 📖 Модальные окна с полным текстом

## Как открыть
Просто откройте `index.html` в любом браузере. Либо разместите на любом статическом хостинге (GitHub Pages, Netlify, Vercel).

## Структура
- `index.html` — весь сайт (HTML + CSS + JS в одном файле)
